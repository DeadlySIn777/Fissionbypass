FissionBypass Pro

CNC G-Code Optimizer for Fusion 360 Personal Use

✅ Installation Complete!

🎯 What Does FissionBypass Do?

  • 🚀
    Restores Rapid Moves: Fusion 360 Personal Use slows down G0 rapid positioning moves to crawling speeds (F2-F5). We restore them to full G0 rapids for positioning moves only.
  • 🔒
    100% Safe: We NEVER touch your cutting feeds, drilling feeds, or any moves that go into the material. Only positioning moves in the air are optimized.
  • ⚙️
    RPM Limiting: Caps spindle speed to your machine's maximum (default 8000 RPM) to prevent damage.
  • 🗑️
    Auto-Cleanup: Deletes useless Fusion parent files and renames files with clean, CNC-friendly names.
  • 👁️
    Auto-Watch: Monitors your Google Drive folder and automatically optimizes any new .nc files you export from Fusion 360.

⚙️ How It Works

1

Export

Post-process your toolpath in Fusion 360 to your Google Drive folder

2

Auto-Detect

FissionBypass detects the new file within seconds

3

Optimize

Rapids are restored, RPM is capped, file is renamed

4

Ready!

Your optimized *_READY.nc file is ready to run

🛡️ This Is NOT a Virus!

  • ✅
    Open Source: The complete source code is available on GitHub. You can review every line of code.
  • ✅
    No Network Access: FissionBypass only reads/writes .nc files in your specified folder. It never sends data anywhere.
  • ✅
    Runs on Startup: Yes, it adds itself to Windows Startup - this is so it automatically watches your folder when you turn on your PC. You can disable this anytime.
  • ✅
    Hidden Window: It runs minimized to stay out of your way. It's not hiding - you can see it in Task Manager as FissionBypass.exe

📁 Installation Locations

Program: %LOCALAPPDATA%\FissionBypass\FissionBypass.exe
Config: %LOCALAPPDATA%\FissionBypass\config.json
Startup: %APPDATA%\...\Startup\FissionBypass.vbs
Uninstall: %LOCALAPPDATA%\FissionBypass\uninstall.bat

To uninstall, simply run uninstall.bat or delete the FissionBypass folder and remove the startup entry.

⚠️ Safety Information

  • 🔧
    Always verify G-code: Preview toolpaths in your CNC software before running. We optimize safely, but double-check is always good practice.
  • 📏
    Check your RPM: Default max RPM is 8000. Edit config.json if your spindle has a different maximum.
  • 📂
    Watch folder: Make sure the configured folder matches where you export your Fusion 360 files.
